Intelligent WMS Exception Agent

×
Challenge & Background

High-volume warehouses experience stock discrepancies during inbound receiving and despatch. Traditional manual investigation takes hours of database querying.

AI Agent Architecture

The agent receives a goal prompt (e.g. "Resolve SKU-9908 discrepancy"), decomposes the workflow into sub-tasks, queries SQL databases via defined tool schemas, identifies mismatch patterns, and outputs a formatted action plan for warehouse manager approval.

Technologies Used
Python Django AI Agent Framework PostgreSQL

Challenge & Objective

Traditional static reorder points fail during demand spikes. This pipeline applies supervised machine learning to forecast order volume based on historical trends and seasonal features.

Machine Learning Implementation

Includes exploratory data analysis (EDA), handling missing warehouse records, feature scaling, model fitting (Linear/Ridge regression, Random Forest), and evaluation with RMSE and R² metrics.
